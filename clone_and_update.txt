THE FOLLOWING REQUIRE ROOT PRIVILEGES
=====================================
1. clear space
   ===========
   $ /usr/bin/octopi-cachecleaner &
   $ bleachbit
   $ sudo bleachbit

2. run clone script (see group 'scripts & files')

3. system update
   =============
   Add/Remove Software with pamac (GUI):
       a. Refresh databases
       b. Updates -> install

   or

   Use command line:
       a. $ sudo pamac update --aur
                or
            paru -Syu --skipreview --noinstalldebug --upgrademenu --removemake \
                 --cleanafter --nokeepsrc --sudoloop --nokeeprepocache \
                 --redownload=all --rebuild=tree
            
       b. $ pamac remove --orphans --unneeded --no-save
                or
            paru --clean # remove unneeded dependencies
            
       c. $ pamac clean --verbose --build-files --keep 0
            paru --Scc   # remove packages not currently installed from repos

   and finally

   $ fwupdmgr update                 # update firmware
   run kodi to update kodi add ons
   run qBitTorrent and update plug ins

4. repeat the first step

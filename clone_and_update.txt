THE FOLLOWING REQUIRE ROOT PRIVILEGES
=====================================
1. run clone script (see group 'scripts & files')

2. system update
   =============
   use bauh package manager (GUI utility)

   or

   $ paru

   then:
   * $ fwupdmgr update # update firmware
   * run kodi to update kodi add ons
   * run qBitTorrent and update plug ins

3. clear space
   ===========
   $ bleachbit
   $ sudo bleachbit

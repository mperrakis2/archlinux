2. system update
   =============
   Add/Remove Software with pamac (GUI):
       a. Refresh databases
       b. Updates -> install

   or

   Use command line:
       a. $ pacaur -Syu              # update including AUR
       b. $ pacaur --aur-cleanall    # offer to remove all built packages
       c. $ paru -Syu --skipreview --noinstalldebug --upgrademenu --removemake --cleanafter --nokeepsrc --sudoloop --nokeeprepocache --redownload=all \
                      --rebuild tree # check if some packages are out of date
       d. $ paru --clean             # remove unneeded dependencies
       e. $ paru --repoctl --clean   # remove packages that are not currently installed from repos

   and finally

   $ fwupdmgr update
   run kodi to update kodi add ons
   run qBitTorrent and update plug ins

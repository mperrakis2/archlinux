THE FOLLOWING REQUIRE ROOT PRIVILEGES
=====================================
1. clear space
   ===========
   $ bleachbit
   $ sudo bleachbit
   * if Kodi is installed, run it to update its add ons
   * if qBittorrent is installed, run it and update its plug ins
   reboot

2. run clone script (man pages: cloneup.sh(1) & cloneup.sh-exclude.conf(5))

3. system update
   =============
   use PacHub package manager (GUI utility)

   or

   $ paru

   then

   $ fwupdmgr update # update firmware

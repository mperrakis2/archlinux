   ============

3. after clone
   ===========
   Add/Remove Software with pamac (GUI):
       a. Refresh databases
       b. Updates -> install

   or

   Use command line:
       a. $ paru -Syu --skipreview --noinstalldebug --upgrademenu --removemake --cleanafter --nokeepsrc --sudoloop --nokeeprepocache --redownload=all --rebuild=tree

       c. $ paru --repoctl --clean

   and then

   $ fwupdmgr update
